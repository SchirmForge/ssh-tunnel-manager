# Obsolete GTK GUI

`gui-gtk` is the superseded SSH Tunnel Manager desktop implementation.

It remains a workspace member on the shared GTK 4.22/libadwaita 1.9 binding generation for
reference and compile compatibility. It is not the default GUI, is not installed or
packaged, and receives no feature or maintenance updates. New GUI work belongs in
`crates/gui-v2`, whose production package and binary are named `ssh-tunnel-gui`.

Removal is not currently planned.
